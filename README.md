# Pluck Trainer (moved)

The bass three-finger roll trainer now lives at **https://2kfest.com/bass/**.
Its code is in [bgnipp/hilltop](https://github.com/bgnipp/hilltop) under `bass/`,
next to the notation engine it uses (`notation/`).

This repo only redirects its old GitHub Pages address there, keeping
links such as `?preset=gallop&bpm=90` or `?seq=ladder` working. The history
of the original app (August 2026) is still here in git.
